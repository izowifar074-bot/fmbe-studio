# 0.2.1 开发交付状态

本记录描述实际代码和验证，不把架构设想当作实现。

当前枪械模式按用户确认的现用AK47技术基线验收；用户明确不要求重验大幅转头消失等客户端边界。五种真实DeepSeek案例、46项测试与具体要求映射见 `gun-mode-audit.md`、`multi-gun-validation.json`。下文通用模拟器未完成项不作为本轮枪械模式的附加门槛。

## 已完成的纵向链路

受限造型程序 → 参数/局部坐标/连接点求解 → 方截面杆分解 → 原版动画命令 → 空白运行实例重放 → 狐狸骨骼与物品矩阵 → 渲染和数值观察 → 局部修改/快照 → 实验导出。

源代码、构建产物、离线资源、运行依赖和 Windows 启停入口均在本目录。工作台监听 127.0.0.1:18120。

## API

- HTTP JSON、WebSocket 修订通知。
- 五个模型工具定义与 dispatch 入口；精简上下文，不默认转储矩阵。
- 原子作者修改、修订冲突、幂等重试、撤销/重做、JSON 导入导出。

## 枪械模式

- 用户当前存档解密与独立LevelDB重放一致：124条有效世界命令、16条独立结构模板。原存档未修改。
- 存档lastOpenedWithVersion和MinimumCompatibleClientVersion均为[1,21,120,0,0]；这不等于精确网易客户端构建号。
- 完整保留75部件参考、几何查表、root/M1运输、身份标签、三姿态、换弹和空仓玩法链。
- 新造型由受限SDK编译，自动分配身份/动作组、计算真实实体成本，导出纯命令mccmd包。
- 手动换弹为源世界的视觉信号；空仓链另有65tick计时、休止和补弹。两者分别预览和验证。
- 真实deepseek-flash生成M4A1：72部件、72狐狸，5轮134746 tokens；连通性另44 tokens。可视反馈、通过的候选和历史均保留，密钥不落盘。
- 枪械专用共享变换由源模型少量部件拟合，其余部件和多摄像机方向独立验证；原始root表达式未修改。
- 模型后续请求失败或工程修订冲突时保留已通过候选，避免丢失工作。

## 重要实现取舍

目前原版通道没有直接提供狐狸相关骨骼的独立 XYZ 可编程 scale。因此高级长方体以方截面杆精确分解；每根杆使用一只狐狸和真实原版动画。分解轴选择以实体数为准，纹理分块方向可能变化，报告中明确列出。

通用模式持物全局矩阵来自社区配方推定；枪械模式使用单独的源模型对照配置。两者均没有按部件目标在渲染层逐个校正，数值残差仍不能代替游戏验证。枪械运行时执行实际动画表达式，但预览的玩法状态和移动时序是明确建模，不是完整命令方块世界/网络模拟。

界面材质与光照是工作台预览，未复刻 RenderDragon 光照、抗锯齿和实体裁剪。
