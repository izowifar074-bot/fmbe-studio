# 枪械模式需求核对

当前范围依据：用户要求在沙盒中加入枪械模式，测试多种枪械，让DeepSeek通过可读接口使用与当前AK47一致的复杂FMBE后端，并输出正确调度的命令。用户随后明确：其现用版本足够，不要求重新研究大幅转头消失等报告中的客户端边界问题。以下以该现用存档为有效技术基线。

## 检查对象与证据

| 要求 | 实现与可检查证据 |
| --- | --- |
| “制作…枪械”自动调用技能 | `isGunPrompt`、`GunAgent`自动读`fmbe-guns/SKILL.md`；真实生成记录含`skill_loaded`和资料读取事件 |
| 低成本模型可表达复杂造型 | SDK提供局部坐标、旋转、循环、连接和部件动作组；DeepSeek真实产物保留源码，超预算时返回高成本部件清单 |
| 多枪型，不仅复刻AK | M4A1、MP5、G17、AWP真实模型调用与工程文件；追加AUG用于新预览反馈流程验证。每例独立提示词、独立工程与独立命令 |
| 狐狸成本真实、没有辅助实体偷增 | 导出G10召唤链实际重放，核对数量、完整编号、材质；少召一只、缺标签、错材质的破坏测试必须报错 |
| 旋转、缩放、骨骼持物转换 | 原版资源运行时；75参考部件多摄像机方向独立角点对照；生成部件的角点残差与安装核对随导出保存 |
| 保留root/M1技术 | 原文表达式相等检查、三次预热和L1阈值回归；没有修改现有运输补偿配方 |

| 独立静音链能执行 | 去掉原全局清理命令后，首条stopsound升级为循环链头，余下连锁和声音内容保留 |
| API构建和直接命令交付 | `/api/agent/run`、工程编辑/导入、动作、读取和导出API；mccmd数字版本1，完整类型/条件/红石/延迟字段与初始化命令 |
| 正确显示模型调用状态 | 生成历史可选择和载入；后续调用失败保留有效候选；预览生成与模型请求送达分别记录，旧版错误措辞显式纠正 |
| 密钥不泄露 | 仅服务进程内存；状态接口不返回密钥；源码、工程、历史、导出和日志扫描；不随压缩包分发data目录 |

## 本轮发现并修复

**以下是沙盒自身的预览、转换和导出缺陷，不是用户原存档的命令遗漏，也不是解密发现了损坏。** 2026-10-11已重新从原ZIP验证解密字节、独立数据库重放，以及124条命令/调度的原样投影；详见`decryption-recheck.json`。

1. 旧预览直接按设计表建立狐狸和标签，可能掩盖实际安装命令错误。现在重放导出的构建命令，检查产物后才进入动画预览。
2. 第5轮提交成功时，截图仅已生成而未进入下一次模型请求，却被旧事件标成“已检查”。现在最多7轮，分别记录`preview_ready`和`preview_delivered`，最终截图尚未送达时保留待检查候选。
3. tick摘要曾遗漏独立跟随链且包含初始化按钮。现在从循环链类型选取，明确排除动画安装链。
4. 保留声音命令、移除全局清理时，原循环头被去掉，导致独立静音区以连锁块开头。现在为声音区设置独立循环头。

## 证据的使用范围

真实模型产物证明这些具体案例能够由DeepSeek设计、接受编译反馈并修正；不作所有未知枪型必然达到相同美术质量的保证。图像反馈是否送达按调用记录判断，不能由存在PNG文件倒推。所有数值检查使用实际动画命令运行结果，未把作者矩阵直接替代渲染结果。

用户已经确认现用AK47版本可用，因此本轮不以重新核验客户端剔除、网络与极端帧率为验收前提。通用沙盒其它功能的未完成项保留在status文档，与本轮枪械模式验收分开记录。

## 完成核对（2026-10-11）

- 五种真实DeepSeek产物：M4A1 72、MP5 73、G17 44、AWP 74、AUG 66狐狸；26次请求，653780 tokens，均低于各自硬预算。AUG验证了新版两次预览实际送达。
- 46项自动测试全部通过；类型检查与生产构建通过。每个模型均覆盖中途切换、组内刚性、连续两次换弹归位、真实构建链、原玩法链内容和调度。
- 各例最大独立角点残差小于7×10^-13格；编号与持物由导出命令重放确认，不由作者表直接伪造。
- 15张固定帧PNG已生成并检查；小型模型取景修正后可清楚查看细节；生成历史实际载入MP5，再恢复AUG，已通过界面确认。
- 发布ZIP在独立端口/数据目录启动，通过75狐狸参考及全部五种工程的导入、导出检查；记录见package-validation.json。包中不带data目录或凭据。
- 本轮发现的构建旁路、截图送达措辞、tick分类、静音循环头问题均已修复并有对应验证。

在用户明确的现用技术基线和上述具体样本范围内，本轮枪械模式目标已完成。后续新枪型继续通过同一编译、实体预算和命令检查流程；不把有限样本扩张成任意提示词均有完美美术效果的承诺。
