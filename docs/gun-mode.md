# 枪械模式交付记录

## 当前基线

源存档：用户提供的 AK47存档_1007(2).zip。SHA256：`ecb78e859e2d5de27b606fc813b6e3de646a580033ada77b59ab111759681df0`。

在工作副本中解密，原文件哈希前后不变。按当前有效 LevelDB 记录读取，独立 MANIFEST/SST/WAL 重放与原生读取的432条键值一致，CRC校验通过。

level.dat中的lastOpenedWithVersion、MinimumCompatibleClientVersion均为[1,21,120,0,0]，InventoryVersion为1.21.120；载荷声明、实际长度和NBT解析均为4142字节。存档版本字段符合目标1.21.120，但不能由此得出精确网易客户端构建号，也不能代替新命令实机验证。原始字段记录见reference/version-metadata.json。

当前世界 **124 个命令方块：9循环、112连锁、3脉冲，12组**。16条结构模板命令独立保存。报告109块与当前世界相比：94条未变、15条修改、15条新增。当前 R001 与报告附录 C23 逐字一致，root 补偿表达式逐字未变。用户确认新增为换弹系统。

当前代码已包含：三姿态、换弹、ammo扣除与显示、空仓休止、reload计时和补弹。当前射线步长0.5，9层c=2，名义512×0.5=256格；报告旧版0.125/64格不再当作当前值。

fire、ammo、reload在世界记分板数据中已经存在；新世界安装包补齐3个dummy目标创建，以及所需初始分数。创建目标与分数初始化是独立按钮，不因“已存在”的失败返回阻断条件连锁。

## 使用流程

输入“制作…枪械”，系统会自动加载 `assets/gun-mode/skills/fmbe-guns/SKILL.md`。模型可调用 gun_reference 获取当前基线、几何SDK、完整AK参考、运行约束和证据，再用 gun_submit 提交造型源码。

模型不直接改root或手写长Molang。编译器负责：

1. 将部件转换为真正可实现的方截面杆，并按实际狐狸计数。
2. 重建5进制身份标签、几何查表和magazine/bolt动作组。
3. 复用当前单一姿态驱动、换弹、root运输、M1采样、跟随和玩法链。
4. 检查原文保护、实体上限、命令长度、非空条件选择器和角点残差。
5. 输出纯命令复制助手JSON与完整文本，不改成行为包或/function。

默认最多7轮模型调用。后续调用失败时保留先前通过验证的候选；修订冲突时不覆盖用户正在编辑的工程。密钥仅存在于进程内存，重启后重新配置。0.2.1分开记录预览生成与模型收到图片，未送达最终图片时不会伪称已检查。

## 保留与适配边界

- 参考AK不改源R001、root、玩法命令；追加前置目标初始化。
- 新作品修改几何查表、动作组ID/弹匣枢轴、身份容量与自定义命名空间。root表达式不改，姿态/换弹时间曲线保持当前基线。
- 实体不足21时，不导出空z分组条件块，避免其失败截断后续root/head/body。实体少于2时拒绝声称512分支。
- 全局kill @e按钮和掉落物/经验球清理原文保存在参考包，不默认加入新作品。静音命令仍保留。
- 移除原清理循环头后，第一条静音命令升为独立循环头，避免没有前置循环块的连锁区永不执行。tick摘要按循环链类型选择，包含跟随，排除初始化按钮和重复动画安装。
- 只装一套当前枪械系统。迁移已有参考世界时先停用旧循环链、保留回退，再按分区替换；不要让两套雪球/记分板逻辑同时运行。
- 三姿态使用短一次性信号，只有一个持续姿态计算器；渲染安装与每tick跟随分离。
- 手动“换弹”标签只触发视觉。当前源世界的空仓链才设置休止/65tick计时/补30弹。视觉2.6秒与逻辑锁定不同，未擅自合并。

## 预览的证据范围

枪械使用独立的源码对照配置：模型Z轴映射、固定旋转符号、位置通道默认值、共享持物变换和渲染原点。配置从少量参考部件拟合，并对其余部件及多个摄像机方向检查；没有按每个部件目标在渲染层修正结果。

正式预览仍然执行真实playanimation表达式和原版骨骼资源。75个参考部件的独立角点比较、多方向视角、换弹组刚性及重新编号后的几何均有测试。

移动预览采用明确的测试时序假设：query读取Pcur，绘制根位置为lerp(Pprev,Pcur,alpha)。源M1表达式在3次预热后能在该模型中抵消非零位移差。这是对源公式的测试模型，**不是已逆向证明网易内部时序**。低帧率漏采、首帧暂态、网络到达、卸载/重进和剔除仍需实机验证。

预览安装后进行3次零时间求值建立身份；不把这个热初始化结果冒充真实冷安装过程。射击按钮展示弹药/休止状态，不模拟真实世界射线碰撞和伤害；导出仍保留当前源命令。
