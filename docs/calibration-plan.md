# 网易客户端最小校准计划

本版没有执行这些测试。不要将这里的用例编号当作已通过记录。

每次采集都记录：网易客户端构建号、平台、世界/资源包清单、实验开关、帧率设置、摄像机位置/方向/FOV、命令执行顺序以及观察时间。

1. 成年狐狸不播放额外动画，嘴持石头；测量中心、三个边方向和大小。
2. 同一狐狸 yaw 0/90/180/270；核对实体基底与模型 -Z 的关系。
3. 只改变 head 位置一个轴，分别测 x/y/z。
4. 只改变 head/body/root 一个轴旋转 90 度；再测两个不对易旋转组合。
5. body 与 head 同时使用 swelling；分别检查统一缩放、双等轴尺寸、父子累计规则。
6. 中性 community advanced 配方；确认 xpos/ypos/zpos 所指的是中心、角点还是其他锚点。本版暂用中心假设。
7. 同一 controller 重复调用同动画与不同动画，记录是否重启、覆盖、保持局部时间。
8. stop_expression 的赋值、return 0/1、条件变真时机；检查调用和逐帧执行次数。
9. blend_out_time 为 0、0.1、1 秒，终止与重入。
10. next_state 省略、空字符串、none、_、已知/未知状态，保留原始输入与游戏输出。
11. 实体本体出视野但持物变换进入视野；远距离、重新加载和重进世界。
12. 玩家第一人称、第三人称前后、快速转向、不同姿态；第二个观看者使用独立记录。

优先使用单实体、单变量场景，记录截图/视频中的物品角点与轮廓。没有可读的内部矩阵时，不虚构骨骼测量。

每项结果包含输入命令、版本指纹、原始观察、拟合参数、残差和未覆盖条件。先更新兼容配置，再运行已有独立几何与命令回归测试。
