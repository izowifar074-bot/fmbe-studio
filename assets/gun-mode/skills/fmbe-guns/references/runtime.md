# 当前存档的运行契约

身份：5进制标签 k47x/k47z/k47y，id=a+5b+25c。每只狐狸的三个标签独立于其当前坐标，堆叠后仍可重装。变量各实体独立，不存在免费跨实体共享。

几何：k0..2 为 forward/up/side 中心，k3..11 为行优先基底。尺寸为 k12、k12、k12*k13*k13。表项每帧重建后才应用动作，不能累计变换。

输出：sleeping 是 R001 与原生 root/head 动画；attack.rotations 输出 body-Y；swelling 同时缩放 body/head；minecart.move.v1.0 做 root 运输；dragon 做固定 head 补偿；warden 输出 body-X/Z。k47e 保留 return0 占位；k47q 持续写 M1。

大尺度运输不写入头部。root 同表达式先采样再消费：alpha回绕，3次预热，L1位移和>3清零，+(1-alpha)*delta。保留 -1、-1/128、18.5、16 等常量，不因看到旧 tp 就删掉。

常态/跑动/机瞄：k90=0/1/2，一次性 return1 信号。R001 唯一持续维护 k91..97；0.22秒 smoothstep，5秒循环，2.2Hz主摆，跑动75度，前向靠近0.21。不新增多个长姿态驱动争写同一变量。

换弹：当前世界 R001 已是 C23。视觉2.6秒；整枪侧倾、magazine组抽出与复位、bolt往返，返回当前姿态。编译器重新绑定生成模型的 magazine/bolt ID，不能沿用 AK 固定数组下标。

弹药：当前世界有 ammo/fire/reload，弹匣30。休止标签阻止相关状态/射击链，reload>=65解除并补30弹。视觉2.6秒与65tick游戏锁定是不同时间尺度，先保留现状。

射击：雪球，9层 c=2 狐狸分支，最多512末端；当前步长0.5，名义推进256格。报告中的0.125/64格为旧版。保留 run execute 重新读取雪球位置，伤害位于分支之后，仅一次；排除狐狸、玩家、雪球。

输入/跟随：手持雪球建立 k47p；狐狸根放眼前2格，tp结尾0 0；渲染一次安装，跟随每tick。初始化与testa/testb/testc分离；换弹标签在消费后移除。动作检测是存档中的启发式，不宣称等同官方按键。

保护仅是 resistance/instant_health/invisibility/slowness，不等同无AI、无碰撞、无重力。未知生命周期、剔除、低帧率与不同设备需单独记录。
