# Third-party resources

## Mojang Bedrock samples

Source: https://github.com/Mojang/bedrock-samples/tree/v1.21.120.4

Commit: `091dbd3ff9cf3c4205eb3c53ba4a673374b08472`.

The selected animation/model/texture resources originate from this tag. The repository's license text is preserved in `assets/MOJANG-LICENSE.md`. These assets remain subject to Minecraft's terms; this application does not claim ownership of them. The resource archive and 245 selected original files were checked against the archive/Git hashes. Derived maps keep the version and source references. Three additional block textures (blue/cyan concrete and copper) were retrieved from the same tag for the supported material palette.

## Community FMBE recipes

Original discussion: https://github.com/szea-ll14/mcbe-cmd-memo/discussions/5

Documentation: https://wiki.bedrock.dev/commands/display-entities

The bundled recipe text is retained as a reference fixture with attribution. The workbench uses the advanced 3D neutral recipe only to infer one explicitly provisional global held-item matrix. This is not engine source code or measured NetEase evidence. Compiler output is generated by the application's own channel/matrix translation.
